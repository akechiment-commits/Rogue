# 立ち絵の表示・作画統一仕様

## ねらい

立ち絵が切り替わっても、同じキャラクターの頭の大きさと顔の位置が変わらない表示にする。武器や魔法、水しぶきなどが横に広い絵でも、それを理由にキャラクター全体を縮めない。

## 現在の表示で起きていること

ゲームの `GameModals.jsx` はPNGの透明でない部分を走査し、その全体がサイドバーに入る縮尺を選んでいる。

```js
scale = min(availableWidth / visibleWidth, availableHeight / visibleHeight)
```

そのため、横に長い攻撃絵は武器や効果を含む横幅に合わせて小さくなる。監査で測った例では、`stand_normal.png` の可視範囲が約395×739px、`battle_melee_2.png` が約543×541px。後者は剣を含めた幅が縮尺を決め、キャラクター本体まで小さく表示される。立ち絵エディタもアルファ範囲全体に合わせてプレビューしており、現状のままでは絵ごとの表示サイズを比較しにくい。

## 採用する表示ルール

1. サイドバーの立ち絵枠は固定する。
2. 全画像に共通の基準絵を置き、頭部の大きさから表示倍率を決める。基準絵は `stand_walk.png`。
3. 表示位置は頭部の目線アンカーを使って揃える。通常、歩行、攻撃、反応で顔の中心が跳ねないようにする。
4. しゃがみ、転倒、横たわりなどは、姿勢クラスごとにアンカー位置を決める。姿勢の違いは残し、カメラ距離は変えない。
5. 武器、髪の先、エフェクトのアルファ範囲は表示倍率の計算に使わない。重要な部分が固定枠からはみ出す絵は、枠内に収まる構図へ修正する。キャラクター全体を縮めて合わせない。

## 各画像に記録するレイアウト情報

ゲームとエディタで共通に読む `portraitLayout` をファイル名ごとに持たせる。座標は元画像の幅・高さに対する0〜1の比率にする。

```js
portraitLayout[file] = {
  scaleBox: { x, y, width, height }, // 頭部・兜の基準範囲
  anchor: { x, y },                  // 両目の中間を通る目線の中心
  poseClass: "upright",             // upright / action / crouched / grounded
};
```

- `scaleBox` は頭部の本体（髪または兜を含む）を囲む。長いアホ毛、なびく髪、武器、魔法効果など、頭部サイズの基準にしない突出部分は含めない。
- `anchor` は目線中央。横顔など目の位置が異なる絵では、顔の正中線上の目線位置を使う。
- `poseClass` は配置用。通常から攻撃へ変わっても同じ表示倍率と目線位置を保つ。大きく姿勢が変わる絵だけ、姿勢クラス内の基準位置へ合わせる。
- 元画像の解像度が違っても座標比で扱うため、PNGの画素数に依存しない。

表示計算はこの情報だけを基準にする。

```text
倍率 = 基準絵の頭部表示高さ ÷ (元画像の高さ × scaleBox.height)
画像位置 = 基準目線位置 − (anchor × 表示後の画像寸法)
```

アルファ境界全体を使った `contain` は立ち絵の倍率決定には使わない。レイアウト情報がない画像を黙って全体フィットへ戻すこともしない。

## 作画・構図ルール

- `stand_walk.png` をキャラクターデザインの基準にする。顔、髪、アホ毛、鎧、頭身を全カテゴリで合わせる。
- 頭部の表示高さと目線位置は、枠内で基準絵と同じにする。顔の表情や身体のポーズだけを変える。
- 人物の胴体や手足がポーズによって動くのは許容する。カメラを引いて全身を縮めることはしない。
- 武器やエフェクトは枠の内側で読める大きさと配置にする。横に長い剣、水流、魔法などは、向き・曲がり・エフェクト幅を調整して収める。
- 立ち絵の端で武器や効果を切らない。枠内に収まらない重要な演出は、絵を描き直すか、キャラクター本体から独立した演出レイヤーとして設計する。
- 通常状態に傷・汚れを加えない。負傷状態では傷の位置と程度を明示し、デザイン確認用の差分でも維持する。

## ゲームとエディタ

- ゲームと立ち絵エディタは同じレイアウト情報と同じ表示計算を使う。
- エディタは `scaleBox`、目線アンカー、固定表示枠を重ねて見せる。基準絵と対象絵を同じ枠で比較できるようにする。
- 枠から重要な絵がはみ出す場合、エディタに警告を表示する。倍率を自動で下げて警告を隠さない。
- 新しい立ち絵や追加スロットにも、登録時にレイアウト情報を設定する。

## 合格条件

1. 通常、歩行、攻撃、アイテム使用、状態、反応、罠の各絵で、頭部表示高さが基準絵の±5%以内。
2. 同じ姿勢クラスでは、目線アンカー位置が固定枠の幅・高さの±3%以内。
3. 頭、髪、アホ毛、武器、重要なエフェクトが不自然に切れない。
4. 絵を切り替えても、キャラクター本体が拡大・縮小して見えない。
5. 鎧あり・なしの差分も、顔、髪、頭身、傷の有無が状態に合い、同じキャラクターとして揃っている。
6. 歩行→近接攻撃→被ダメージ→状態異常→アイテム使用→罠反応を連続して切り替え、頭部サイズと位置を確認する。

## 適用順

1. 共有レイアウト情報と共通表示計算を追加する。
2. エディタで `stand_walk.png`、`battle_melee_2.png`、`reaction_trap_watergun.png`、`reaction_trap_mp_absorb.png` を同じ枠に並べ、倍率・アンカー・はみ出し表示を調整する。
3. 監査済みのゲーム内243枠すべてに `scaleBox` と `anchor` を登録する。未登録をエディタで一覧化する。
4. ゲーム表示を共通計算へ切り替え、カテゴリ別の連続切替で目線・倍率・切れを確認する。
5. 固定倍率ではみ出す絵を、優先順位を付けて構図修正する。最初は剣・水流・吸収効果など横幅が倍率を押し下げる絵。

## やらないこと

- 画像全体の透明範囲に合わせて立ち絵ごとに倍率を変える。
- 武器やエフェクトを収めるためにキャラクター本体を縮める。
- 表示倍率を統一したように見せるため、重要な絵を枠端で切る。
- 立ち絵ごとに目測で顔サイズや頭身を変える。
